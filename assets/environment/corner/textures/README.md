# Sanctum quality-corner materials

Three newly authored, seamless 1024 × 1024 material sets, covering four metres
per repeat. Generated by `tools/build_corner_materials.py` from periodic Blender
4D material graphs. These are fresh detail fields at twice the earlier linear
resolution, not enlarged copies of the 512px Sanctum slice maps.

| Prefix | Surface | Maps |
|---|---|---|
| `floor` | Warm aged limestone, soft mineral variation and shallow pores | albedo, normal, roughness |
| `basalt` | Dark neutral volcanic stone, sparse pale mineral flecks | albedo, normal, roughness |
| `bronze` | Cast bronze with irregular matte green oxidation | albedo, normal, roughness, metallic |

Albedo is sRGB and contains only intrinsic color, with no baked lights, shadows,
or ambient occlusion. Scalar maps use the red channel in linear space. Normals
use the OpenGL/Godot tangent convention (+Y). Relief is derived from height in
metres; use normal scale 1 as a starting point. Bronze's metallic map makes the
exposed alloy reflective and the oxidized patches mostly dielectric. Multiply
that map by a material metallic value of 1, not by the old uniform bronze value.

All import files enable mipmaps. Color and scalar maps use lossless storage to
avoid block artifacts during this visual comparison. Normal imports are marked
as normal maps. The manifest records dimensions, storage, channel ranges and
pixel-exact opposite-edge checks. Ten source PNGs occupy approximately 8 MiB;
the full imported GPU allocation with mipmaps must be measured in the target
renderer rather than inferred from compressed PNG size.

## Art direction

Use limestone on walking surfaces and a few carved edges, basalt for recessed
and structural stone, and bronze sparingly on borders and focal details. Use
neutral material tint (white) first: these maps already define surface color.
Keep block-to-block tint variations modest. Lighting should supply contact
shadow and depth; geometry should supply slab joints, chipped outlines and
bevel highlights. Large black cracks painted into every tile would make the
arena busy and flatten its lighting.

The floor intentionally stays quiet enough to read combat silhouettes. The
bronze patina has the strongest macro pattern and should occupy a small share
of the screen. Warm accent lighting against the dark basalt gives a stronger
architectural hierarchy without needing bright purple fill everywhere.

## Regeneration

Run from the repository root:

```sh
blender -b --factory-startup -noaudio --python tools/build_corner_materials.py
```

Blender 5.2 / Cycles CPU was used. Bake target graphs are emissive, so results
contain no scene illumination. The explicit periodic endpoint constraint also
removes tiny bake-sample differences along texture boundaries.

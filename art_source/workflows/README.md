# Starfall workflows

- **[Starfall Model Forge v2](starfall-model-forge-v2/CURRENT.md)** is the approved default for future class models, materials, animation and fitted body hitboxes. It combines the unchanged Fulcrum baseline through r008 with the required hitboxes-v1 extension and excludes reverted r006/r007. Its extended record, verification and finishing steps are linked from CURRENT.md.
- [Starfall Character Forge v1](../../docs/STARFALL_CHARACTER_FORGE_V1.md) is the preserved historical character workflow; use only when explicitly requested.
- [Starfall Spell Forge](starfall-spell-forge/README.md) is the separate evolving spell-effects workflow.

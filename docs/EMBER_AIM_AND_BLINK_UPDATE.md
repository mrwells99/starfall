# Ember aim and Blink update — 2026-09-09

Implemented directly in the project source. Matching client/server builds are required because the action RPC now includes camera heading. No exported client, commit, push or server deployment was made.

## Solar Flare

- 4m reach, with a **108-degree cone** (54 degrees either side of character forward). This incorporates the requested 10% reduction from the initial 120-degree width.
- Casts immediately in the character's current aim direction without requiring a selected enemy. Selecting an ally, a distant enemy, or nothing does not change its aim.
- Every hostile actor inside the cone is checked independently against terrain line of sight and world-duel permissions. Allies and protected bystanders are excluded.
- Existing effect remains: up to 3s incapacitate, broken by damage, with incapacitate diminishing returns, an 18s cooldown and the normal GCD.
- A simple orange cone outline follows the local Ember for **one second after a successful cast**, including a miss, and is otherwise hidden. Rejected casts do not extend the window. Visibility uses the first second of the existing replicated cooldown, so it needs no extra network message or timer state. It shares radius/angle constants with hit detection and uses a cached mesh/material. This first outline is flat; it does not drape over slopes or draw a custom clipped shape around obstacles. Solid terrain still blocks actual hits.

## Blink

- Two stored charges, restoring **one every 14s**, sequentially. Spending the second charge does not restart the first charge's timer.
- Up to 8m along movement input sampled at the instant of casting, including backward, strafe and diagonal input. Diagonals are normalized to the same distance.
- Without directional input, follows the camera's horizontal heading, including free look. Residual airborne velocity does not override that fallback.
- Off the global cooldown; neither waits for nor restarts it. Existing control and active-cast restrictions remain.
- The existing swept movement stops the character before terrain and preserves jump velocity. No client-provided destination or speed is accepted.
- The hotbar displays a corner charge badge and the next-charge countdown. An available recharging charge uses a lighter sweep; zero charges use the ordinary cooldown sweep.
- Authoritative charge count lives in `identity.blink_charges`; the existing cooldown array carries the next recharge timer. Both replicate together. Round/duel identity resets restore two charges.
